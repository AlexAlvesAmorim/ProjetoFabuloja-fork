# Plano de Estudo Node.js do Zero ao Avançado

## 🎯 Objetivo
Ser capaz de desenvolver APIs completas, trabalhar com bancos de dados, autenticação e deploy de aplicações Node.js.

---

## 📅 Módulo 1: Fundamentos JavaScript (1 semana)
**Prerequisição:** Você precisa conhecer JavaScript básico.

- [ ] Variáveis, constantes e tipos de dados
- [ ] Funções (arrow functions, parâmetros defaults)
- [ ] Loops e condicionais
- [ ] Arrays e objetos métodos (map, filter, reduce)
- [ ] Promises e async/await
- [ ] Destructuring e spread operator
- **Exercício:** Criar um pequeno script que processa uma lista de produtos

---

## 📦 Módulo 2: Introdução ao Node.js (1 semana)
- [ ] O que é Node.js e diferença entre Node e navegador
- [ ] Comandos básicos: `node`, `console.log`, processamento de argumentos
- [ ] Módulos built-in: `fs`, `path`, `os`, `url`, `http`
- [ ] Sistema de módulos: `require` vs `import`
- [ ] `npm` e gerenciamento de pacotes
- [ ] Criando seu primeiro servidor HTTP
- **Projeto:** Servidor simples que responde "Olá Mundo" em diferentes rotas

---

## 🌐 Módulo 3: Express.js (1 semana)
- [ ] Instalação e configuração do Express
- [ ] Rotas GET, POST, PUT, DELETE
- [ ] Middleware (o coração do Express)
- [ ] Express Router para organizar rotas
- [ ] Parâmetros de rota e query strings
- [ ] Tratamento de erros
- **Projeto:** API de tarefas (CRUD básico) com Express

---

## 🗄️ Módulo 4: Bancos de Dados (1-2 semanas)
Escolha UM:

**Opção A - SQL (PostgreSQL):**
- [ ] Instalação do PostgreSQL
- [ ] npm `pg` ou `sequelize`
- [ ] Conexão e queries básicas
- [ ] ORM Prisma (recomendado para modernidade)

**Opção B - NoSQL (MongoDB):**
- [ ] MongoDB Atlas (cloud) ou local
- [ ] npm `mongoose`

- [ ] CRUD operations with database
- [ ] Modelos/Schemas
- [ ] Relações entre dados

**Projeto:** Integre sua API Express com o banco de dados

---

## 🔐 Módulo 5: Autenticação e Segurança (1 semana)
- [ ] JWT (JSON Web Tokens) - como gerar e validar
- [ ] Hash de senhas com bcrypt
- [ ] Rotas protegidas (middleware de auth)
- [ ] Login/logout flow
- [ ] Boas práticas de segurança (helmet, cors, rate-limit)

**Projeto:** API completa com login, registro e rotas protegidas

---

## ⚡ Módulo 6: Arquivos e Uploads (3-4 dias)
- [ ] Operações com sistema de arquivos (`fs/promises`)
- [ ] Upload de arquivos com `multer`
- [ ] Validação de tipos de arquivo
- [ ] Armazenamento em nuvem (opcional: Cloudinary)

**Projeto:** API que permite upload de perfis/imagens

---

## 📦 Módulo 7: Boas Práticas e Testes (1 semana)
- [ ] Estrutura de pastas organizada
- [ ] Variáveis de ambiente (.env)
- [ ] Nodemon para desenvolvimento
- [ ] Unit tests com Jest ou Vitest
- [ ] Postman / Thunder Client para testar APIs

---

## 🚀 Módulo 8: Deploy e Produção (3-4 dias)
- [ ] Variáveis de ambiente em produção
- [ ] Render.com ou Railway para deploy
- [ ] Docker básico (conexão com o que você está aprendendo agora!)
- [ ] Health checks e logs

---

## 💡 Projetos Práticos (faça ao longo do caminho)

1. **Projeto 1 - API de Lista de Tarefas** (Módulos 3-5)
2. **Projeto 2 - API de E-commerce** (todos os módulos)
3. **Projeto 3 - Clone do Twitter (mini)** - com posts, likes, comments
4. **Projeto 4 - API de Galeria de Fotos** - com upload e Cloudinary

## 💡 Dicas Importantes

1. **Pratique todos os dias** - mesmo 1h faz diferença
2. **Não copie cegamente** - digite o código manualmente
3. **Erre muito** - debug é parte do aprendizado
4. **Use a versão LTS** do Node (atual v20)
5. **Pergunte ao Google** - saber pesquisar erros é habilidade de dev
